首次使用：创建仓库专用令牌
  1. 打开 GitHub 令牌创建页面，填写名称 S7 网站管理，并选择适合的到期时间。
  2. Resource owner 选择 fuxuecheng179-sudo。
  3. Repository access 选择 Only select repositories，只勾选 s7-gun-codes。
  4. Repository permissions → Contents 选择 Read and write；Metadata 的 Read-only 保持默认。
  5. 点击 Generate token，把生成的令牌粘贴到下面。令牌只显示一次，请自行妥善保管。
